## Scope

`TplQueue.Abstractions` owns the shared public contracts that the rest of the TplQueue package line builds on.

It is the right repository when you need to understand:

- which contracts are public and stable
- how payload, serializer, queue, retry, and observer abstractions fit together
- how to build and validate the contract package locally
- how packaging and release operations affect the abstraction layer
